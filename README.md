# Tasty-Food-Website
Web Development
I developed the Omni Food Delivery Website, a platform dedicated to exploring a rich array of culinary content. The website is designed to engage users with mouth-watering recipes, stunning food photography, and captivating stories from the culinary world. The goal was to create an online space where food enthusiasts could discover new recipes, learn about various cooking techniques, and enjoy insightful chef interviews, all in one place.

To achieve this, I focused on creating a user-friendly interface that would make navigation simple and enjoyable. I carefully designed menus, categories, and filters to help users easily find the content they’re interested in. The website's visual appeal was enhanced by integrating high-quality images and a clean, modern layout.
